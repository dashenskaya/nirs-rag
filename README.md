# Meme helper - попомщник в нахождении мемов

Продукт представляет из себя чат, которые поможет подбирать забавные ответы по запросам, объяснит, что значит подобранный мем и скажет, насколько он актуален и как появился

# Команда

Наша команда состоит из трёх человек:
- Бабере Виктория - великолепный фронтендер
- Николаева Даша - невероятный бекендер
- Шерстеникин Никита - скромный отвечающий за нашу бд и интеграцию RAG

# Структура репозитория и описание файлов

Репозиторий состоит из нескольких основных папок и файлов:

- README - Вы читаете его сейчас! Файл с базовой информацией о проекте
- CHANGE_HISTORY - Файл с всеми внесёнными изменениями в наш проект
- AGENTS - файлик с правилами проекта и всеми необходтимыми напоминаниями ддля участников проекта
- /app - все файлы, связанные  сс амим приложением
- /benchmark - Все файлы, связанные с бенчмарком
- /spec - файл, сордержащий разные SDD-описания проекта(на данный момент только продуктовое)
- /tests - файл с тестами кода нашего проекта
